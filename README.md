# Pamp Lab

Catálogo de peças em cerâmica fria, com 24 produtos, fotos, preços e dimensões.

## Recursos

- Busca por título e filtros por categoria.
- Layout adaptado para celular, tablet e computador.
- Movimento suave nos produtos ao passar o mouse, respeitando a preferência por movimento reduzido.
- Imagens WebP otimizadas.

## Publicar na Vercel

Importe este repositório como um novo projeto e selecione **Other** em Framework Preset. Use a raiz do repositório. Não é necessário instalar dependências nem executar um comando de build. Se solicitado, use `.` como diretório de saída.

## Arquivos

- `index.html`: catálogo público.
- `assets/`: imagens dos produtos e da marca.
- `vercel.json`: configuração de hospedagem.

A edição do catálogo é feita no arquivo editável separado. O site público não inclui controles administrativos.
